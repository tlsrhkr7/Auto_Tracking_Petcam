# Auto Tracking Petcam

YOLO 기반 실시간 객체 검출과 서보모터 제어로 반려동물을 자동 추적하는 스마트 펫캠입니다.

## 개요

외출 중 반려동물의 위치를 실시간으로 확인하기 어렵고, 기존 홈캠은 수동 조작이 필요하며 반려동물이 화면에서 벗어나는 문제가 있습니다. 본 프로젝트는 자동 추적 기능으로 이를 해결합니다.

## 하드웨어

| 구성 | 설명 |
|------|------|
| Topst D3 | 메인 임베디드 보드 (카메라 연결 및 서보모터 제어) |
| 카메라 | 실시간 영상 촬영 |
| 서보모터 | 바운딩 박스 중심 좌표 기반 카메라 방향 제어 |
| 노트북(PC) | YOLO 모델 실행 및 Flask 서버 운영 |
| LED | 인지 / 추적 / 완료 상황 시각화 |
| 부저 | 제어 명령 입력 시 알림 |

## 시스템 아키텍처

```
[부저]  ─┐
[LED]   ─┼─→ [TOPST D3] ──(TCP 통신)──→ [PC]
[서보모터]┘        ↓                         ↕ (Flask 통신)
                [Camera] ────────→ [YOLO]  [스마트폰] ←──(무선 통신)──→ [웹사이트]
                                                                              ↓
                                                                          [UI / Control]
```

- **TOPST 보드**: 부저·LED·서보모터 제어
- **PC**: YOLO 실시간 객체 검출, 바운딩 박스 중심 좌표 계산·전송
- **스마트폰**: Flask REST API 서버, 영상·검출 결과 뷰어
- **웹사이트**: 실시간 영상·검출 상태 대시보드, 제어 명령 입력

## 기술 스택

YOLO v11n · C++(Topst D3) · Python / Flask · JavaScript / CSS · TCP 소켓

## 문제점 및 향후 계획

- 서보모터 성능 한계로 완전한 180도 회전 불가 → 180도 지원 모터로 교체
- 카메라 연결 불안정 → 고화질 카메라로 교체
- 데이터 전송량에 비례한 웹사이트 렉 발생
- 향후: 다중 카메라 동시 관리, 모션·행동 인식, 상하 제어 구현
