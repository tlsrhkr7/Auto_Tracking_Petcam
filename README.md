# 🐾 Auto Tracking Petcam

> **반려동물 자동 추적 펫캠 프로젝트** — YOLO 기반 실시간 객체 검출과 서보모터 제어를 통해 반려동물을 자동으로 추적하는 스마트 홈캠 시스템입니다.

---

## 📌 프로젝트 개요

외출 중 반려동물의 위치와 행동을 실시간으로 파악하지 못해 보호자의 불안이 지속되는 문제를 해결하기 위해 개발된 프로젝트입니다.

기존의 홈캠은 사람이 직접 수동 조작을 해야 했으며, 반려동물이 프레임에서 이탈하거나 녹화 사각지대가 발생하는 문제가 있었습니다.
본 프로젝트는 **자동 추적 기능**을 통해 반려동물의 이상 증후를 파악할 수 있는 스마트 펫캠을 구현합니다.

---

## 🔧 하드웨어 구성

| 번호 | 하드웨어 | 설명 |
|------|----------|------|
| H/W 1 | **Topst D3** | 메인 임베디드 보드 (카메라 연결 및 서보모터 제어) |
| H/W 2 | **카메라** | Logitech 웹캠 — 실시간 영상 촬영 |
| H/W 3 | **서보모터** | 바운딩 박스 중심 좌표 기반 카메라 방향 제어 |
| H/W 4 | **노트북 (PC)** | YOLO 모델 실행 및 Flask 서버 운영 |
| H/W 5 | **GPIO** | 보드와 주변기기 간 연결 인터페이스 |
| H/W 6 | **LED** | 인지 / 추적 / 완료 상황 시각화 |
| H/W 8 | **부저** | 제어 명령 입력 시 소음 출력 알림 |

---

## 🏗️ 시스템 아키텍처

```
[부저]  -+
[LED]   -+-> [TOPST D3] --(TCP 통신)--> [PC]
[서보모터]+        |                         | (Flask 통신)
                [Camera] --------> [YOLO]  [스마트폰] <--(무선 통신)--> [웹사이트]
                                                                             |
                                                                         [UI / Control]
```

### 각 컴포넌트 역할

**TOPST 보드**
- 부저: 제어 명령 입력 시 소음 출력
- 서보모터: 바운딩 박스 중심 좌표를 통한 추적 제어
- LED: 인지, 추적, 완료 상황 시각화

**PC**
- YOLO 실시간 객체 검출
- 바운딩 박스 중심 좌표 계산 & 전송

**스마트폰**
- Flask REST API 서버 (PC <-> 스마트폰) 연동
- 영상 / 검출 결과 뷰어

**웹사이트 (UI / Control)**
- 실시간 영상 · 검출 상태 대시보드
- 제어 명령 입력 (예: 부저 ON/OFF)

## ⚠️ 문제점 및 향후 계획

### 현재 문제점

- **서보모터 성능 한계**: 완전한 180도 회전 불가능 및 불안정한 동작
- **카메라 센서 연결 불량**: Topst 보드와 카메라 연결 상태 불량 및 성능 부족
- **웹사이트 렉 발생**: 사용자 데이터 전송 속도에 비례하여 잦은 렉 발생

### 향후 계획

**하드웨어 업그레이드 및 안정화**
- 180도 지원 서보모터로 교체 및 제어 알고리즘 강화
- 연결성 높은 고화질 카메라 사용

**사용자 편의성 및 기능 추가**
- 2대 이상의 카메라 동시 관리 기능
- 간단한 모션 · 행동 인식 기능 추가
- 상하 제어 구현
